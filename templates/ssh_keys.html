How keys are used
  1. On instance creation, pick a saved key — it is installed for root and for the web-console account.
  2. Instances created with a key and no password have password login disabled; SSH becomes key-only.
  3. The in-browser terminal uses Incus exec, so it does not need an SSH password.
  4. Deleting a key here does not change instances that already have it installed — rebuild one to rotate.
