Single-binary Go console for Incus

Cloud-style control for your own Incus server

Peaceful Cloud Console gives you a clean, Lightsail-style web interface to launch and operate Incus containers and virtual machines on a single host—complete with browser terminal, SFTP file manager, Caddy HTTPS, and S3 backups.

How it works

Three focused layers keep infrastructure in Incus, state in SQLite, and public routing in Caddy.

1. Web Console

Go + HTMX + SQLite

One static binary embeds all HTML templates, CSS, and terminal assets. SQLite stores only metadata: users, sessions, domains, metrics, and audit logs.

2. Infrastructure

Incus over Unix Socket

Talks directly to incusd over its local Unix socket for containers, VMs, ZFS storage pools, snapshots, and live exec terminals. Incus stays the source of truth.

3. Public Edge

Caddy & Dedicated IPs

Instances run on a private bridge while Caddy handles automatic Let's Encrypt HTTPS for custom domains, alongside optional 1:1 dedicated public IP forwarding.

Features & walkthrough

Arranged in the natural workflow—from launching your first instance to networking, backups, and access security. Click any screenshot to inspect it full-size.

01 / Dashboard

Getting started & host overview

See running instances, CPU/memory/storage utilization, recent activity, and quick onboarding actions from one screen.

  • Live host capacity and resource totals
  • Quick links to create instances, SSH keys, and domains
02 / Fleet

Instances list & lifecycle actions

Search and filter containers and virtual machines, inspect private and dedicated IPs, and run start, stop, or reboot actions.

  • Strict per-tenant ownership isolation across operators and viewers
  • Instant jump to web console, metrics, or storage
03 / Create — Step 1

Choose OS or application blueprint

Provision fresh Linux distributions or prebuilt application images from a curated blueprint catalog.

  • Supports OS images (Ubuntu, Debian, Alpine, etc.) and custom app aliases
  • Works identically for LXC containers and QEMU virtual machines
04 / Create — Step 2

Choose size, workload type & storage

Pick preset compute plans or customize vCPU, RAM, disk size, and target storage pool before launch.

  • Select container or full VM virtualization per workload
  • Enforces host-wide and per-user instance quotas
05 / Create — Step 3

Attach SSH keys & launch script

Inject saved public keys from your vault, optionally pass cloud-init / startup scripts, and review the launch summary.

  • Creates an unprivileged cloud-user account with passwordless sudo
  • Tracks provisioning progress live via background jobs
06 / Instance Control

Instance details & historical metrics

Inspect CPU, memory, disk, and network charts across 1h to 30-day windows alongside storage, domains, and configuration tabs.

  • Built-in metric sampling stored locally in SQLite
  • In-place resize, rename, rebuild, and owner assignment
07 / Shell & Files

Browser terminal & SFTP file manager

Open a WebAssembly-powered interactive shell and side-by-side SFTP file browser directly inside the instance over Incus exec—no open SSH port required.

  • Parallel file uploads, downloads, copy/paste, and path insertion
  • Strict origin checks, idle timeouts, and session-bound SFTP cleanup
08 / Networking

Domains, dedicated IPs & port forwarding

Route HTTPS domains through Caddy, bind 1:1 dedicated public IPs from an admin-managed pool, or expose individual TCP/UDP ports.

  • Automatic Let's Encrypt TLS certificates for attached domains
  • Per-instance L2/L3 bridge filtering prevents cross-tenant spoofing
09 / Snapshots

Instant copy-on-write snapshots

Take fast local rollback points before upgrades or configuration changes, and automate recurring snapshots with retention pruning.

  • One-click restore or delete directly from the instance tab
  • Optional scheduled auto-* snapshots with configurable retention
10 / Backups

Portable backups & S3 off-site archives

Export full instance archives to local disk and replicate them to any S3-compatible object store (AWS S3, MinIO, R2, B2) or Restic repository.

  • Restore archives into existing or new instances
  • Survives single-host disk loss when off-site storage is enabled
11 / SSH Vault

Tenant-isolated SSH key vault

Store existing public keys or generate fresh Ed25519 keypairs in the browser—the private key is shown once and never persisted.

  • Each user manages their own keys with fingerprint verification
  • Selectable during instance creation or admin provisioning
12 / Security

Two-factor authentication, RBAC & OIDC SSO

Protect every account with TOTP authenticator codes and one-time recovery codes, alongside encrypted OIDC SSO and multi-session management.

  • Roles: admin, operator, and viewer
  • Audit logging, login throttling, and active device revocation

Install & deploy in minutes

Build a single static Go binary with embedded assets, point it at your Incus socket, and run it behind Caddy and systemd.

git clone https://github.com/PeacefullCloud/cloud-console
cd cloud-console
CGO_ENABLED=0 go build -trimpath -o cloud-console .
cp .env.sample .env
./cloud-console
