What happens next
  1. The instance is created from the selected image on the Incus host.
  2. CPU, memory and root disk limits are applied.
  3. The instance is started and gets a private address on the Incus bridge.
  4. Caddy is re-rendered so the domain reaches the container with automatic HTTPS.
  5. The instance appears as Running on the Instances page.
